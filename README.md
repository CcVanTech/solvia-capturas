# solvia - capturas

Página con capturas de ejemplo de Solvia, una plataforma web para importadores que reúne inventario, compras y embarques. Sirve para enlazarla en los correos de presentación.

## Contenido
- `index.html`: página con 4 capturas explicadas y el botón «solicitar demo gratis».
- `img/`: capturas optimizadas que usa la página.
- `originales/`: las 7 capturas originales (login, inicio, inventario, compras y producción, embarques, pedidos arribados, alertas).

## Cómo usarlo
Se publica con GitHub Pages desde la rama `main`: https://ccvantech.github.io/solvia-capturas/

Para verla en el computador, abre `index.html` en el navegador.
